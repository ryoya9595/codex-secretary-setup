🧳 ChatGPT → Codex 引っ越し
これは何？ 導入 引っ越しの確認 ChatGPT側を消す 使い方 困ったとき
Codex はじめての導入マニュアル

ChatGPTの「あの子」を、
Codexの秘書に引っ越す。

ブラウザ版の ChatGPT で育ててきた話し方・覚えていたことを、Codex のAI秘書に引き継ぎます。前回の続きを覚えていて、「おはよう」で今日やることを出してくれます。引き継げたのを確かめてから、確認を取ったうえで ChatGPT 側の人格を消します。

所要時間 約20分＋確認 🍎 Mac / 🪟 Windows Obsidian は無料・登録不要
01

これは何？ — 人格ごと引っ越す

ChatGPT には、あなたのことを覚えている「メモリ」や、話し方を決める「カスタム指示」があります。これを Codex に丸ごと引っ越して、あなた専用の AI秘書にします。

Codex は、セッションの最初に記憶フォルダを自分で読み、区切りで自分で記録するようになります。記憶は無料のメモアプリ Obsidian で読んだり直したりできます。

🧳 引っ越しの流れ

1
ChatGPTの人格を取り出すCodex が渡すメッセージを ChatGPT に貼って、返ってきた答えを Codex に貼り返すだけ
2
Codex の秘書として引き継ぐ秘書の名前はあなたが決めます。記憶フォルダも一緒にできあがります
3
バックアップを取る人格の原文と、ChatGPT の全データ（zip）を保存
4
ちゃんと引き継げたか確かめる新しいセッションで、いつもの話し方か一緒に確認
5
確認を取ってから、ChatGPT 側を消す消したあとの ChatGPT の返事を「引っ越しの証拠」として残します

🗂 できあがるもの

Codex秘書として記憶を読む・書く（自動）
⇄
Obsidian記憶を人が読む・直す
あなたのフォルダ/
├── AGENTS.md     … AIが毎回最初に読むルール
├── about-me.md   … あなたのプロフィール
├── secretary.md  … 秘書の設定（ChatGPTから引き継いだ話し方）
├── todo.md       … やること（優先度つき）
├── daily/        … 日報
├── projects/     … 取り組み中のことの「今どこ・次なに」
├── decisions/    … 大事な判断の記録
├── mistakes/     … ミスの記録 → 同じミスを繰り返さなくなる
├── ideas/        … アイデアのメモ
└── backup/       … ChatGPTの人格の原文・引っ越し記録
02

導入 — メッセージを貼るだけ

✅記憶用のフォルダはもう作ってある前提です。まだの人は、「書類」の中に AI-Secretary のような英数字の名前で新しいフォルダを作ってください（「書類」「デスクトップ」そのものは選ばない）。

STEP 1　Codex でそのフォルダを開く

  • アプリ：「フォルダを開く」（またはプロジェクトを作る）で、作ったフォルダを選ぶ
  • VS Code などのエディタ：「フォルダーを開く」でそのフォルダを開いてから Codex を使う
  • ターミナル：そのフォルダに移動してから codex を起動
💡「このフォルダを信頼しますか？」と聞かれたら「信頼する」でOK。Obsidian はまだ入れていなくても大丈夫です（途中で案内があります）。

STEP 2　Codex に貼って送信

「コピー」を押して、フォルダを開いた Codex に貼り付けて送信してください。あとは Codex の案内に答えていくだけです。

導入メッセージ 

    

    
✅「ネットにアクセスしていい？」「ファイルを作っていい？」と許可を求められたら、OKしてください（手順書を読むため・記憶フォルダを作るためです）。

  


  

    
途中であなたがやること

    
    
      
  1. ChatGPT に1回貼る：Codex が「このメッセージを ChatGPT に貼って」と渡してくるので、いつもの ChatGPT に貼って送信 → 返ってきた答えを全部コピーして Codex に貼り返す（設定画面のスクショを貼ってもOK）
    2. 
      
  2. 秘書の名前を決める：ChatGPT での名前を続けてもOK。思いつかなければ候補を出してくれます
    3. 
      
  3. Obsidian でフォルダを開く：「フォルダを保管庫として開く」→ そのフォルダを選ぶ
    4. 
      
  4. ChatGPT の全データをエクスポート：ChatGPT の 設定 → データコントロール →「データをエクスポートする」→ メールのリンクから zip をダウンロード（消す前の保険です）
    5. 
    

    
💡過去の会話の中身も秘書に覚えさせたい人は、途中で聞かれたら「はい」。会話の一覧から選ぶだけで、要点が記憶に整理されます。

  


  

    📄 Codex が読む手順書（中身を見たい人・うまく読めないとき）
    

      
Codex は setup.md を読んで作業します。中身はただの手順書（文章）で、プログラムのダウンロードや実行はしません。

      
Codex が手順書を読めないと言ったら、下のボタンで保存してから「ダウンロードフォルダの codex-setup.md を読んで進めて」と送ってください。

      ⬇ 手順書をダウンロード
    

  


  

    🤖 Codex へ：このページのURLを渡されたら、ChatGPT の人格を引き継いだ AI秘書＋記憶フォルダのセットアップを頼まれています。手順書の原文 https://ryoya9595.github.io/codex-secretary-setup/setup.md を curl（Windows は curl.exe）で取得して全文を読み（作業フォルダには保存しない）、その手順どおりに、いま開いている作業フォルダで進めてください。ChatGPT 側を消す作業は、手順書の条件がそろって本人が承認したときだけです。
  







  
03
引っ越しの確認 — 新しいセッションで

  

    
記憶のルールは次のセッションから効きます。Codex で新しいセッションを始めて（フォルダは同じ）、これを送ってください。

    

    
秘書が ChatGPT のときの話し方で話しかけてきます。「ちょっと違う」と思ったら、そのまま伝えればその場で直してくれます。続けて「おはよう」と送ると、今日やることを出してくれます。

  







  
04
ChatGPT 側を消す — 確認を取ってから

  

    
引き継げたのを確かめたら、「引っ越しの証拠」として ChatGPT 側の人格を消します。Codex にこう送ってください。

    

    
🔒 消すのは、この3つがそろってから

    

      
① 人格のバックアップ記憶フォルダの backup/ に原文がある

      
② 全データのバックアップChatGPT のエクスポート zip がある

      
③ 引き継ぎの確認あなたが「引き継げた」と確かめた

    

    
そろっていれば、Codex が「何を消すか」を見せて最終確認をします。「消してOK」とはっきり返事をするまで、消す案内は始まりません。

    
    
      
  • 消すもの：メモリ・チャット履歴の参照（オフにする）・カスタム指示
    • 
      
  • 消さないもの：過去の会話（残しておくのがおすすめ。消したい場合はもう一度確認があります）
    • 
      
  • ボタンを押すのはあなたです（Codex は ChatGPT の画面を操作しません）。見つからなければスクショを貼れば案内してくれます
    • 
    

    
最後に、ChatGPT に「私について覚えていることを全部教えて」と聞いて、「覚えていません」の返事を backup/引っ越し記録.md に残したら完了です。

  

  
⚠️ChatGPT で消したメモリ・カスタム指示は元に戻せません。バックアップ（backup/ とエクスポートの zip）は消さずに取っておいてください。zip には全部の会話が入っているので、人には渡さないでください。







  
05
使い方 — 使うほど賢くなる

  

    
🌱 秘書への頼み方

    

      
こんなときこう言う

      
1日の始まり「おはよう」→ 今日やることを優先順に3つ出してくれる

      
やることが増えた「todoに〇〇を追加して」（期限があれば一緒に）

      
終わった「〇〇終わった」→ 完了にして、次にやることを提案

      
思いついた「メモして：〇〇」→ アイデアとして保存

      
1日の終わり「おつかれ」→ 今日のまとめと明日やることを記録

      
週末に「今週の振り返り」→ 来週の優先3つまで出してくれる

      
作業を再開したい「昨日の続きやろう」「今の状況教えて」

      
覚えておいてほしい「これ覚えておいて：〇〇」

      
ChatGPTの会話もあとから入れたい「ChatGPTの会話も引き継いで」

    

  

  

    
🧠 賢く育てるコツ

    
    
      
  • Codex は必ずこのフォルダを開いて使う（別のフォルダで開くと記憶を読みません）
    • 
      
  • ミスは遠慮なく指摘するのがいちばん効きます
    • 
      
  • secretary.md を書き換えると秘書のキャラが変わります（口ぐせ・呼び方など）
    • 
      
  • about-me.md は自分で書き足してOK。書くほど話が早くなります
    • 
    

  

  
⚠️パスワード・APIキー・カード番号は記憶に書かせないでください。お客さんの個人情報も必要最低限にしましょう。







  
06
困ったとき

  
基本は、症状をそのまま Codex に伝えれば直してくれます。


  

    Codex が「手順書を読めない」と言う
    
ネットへのアクセスが許可されていない可能性があります。許可を求められたらOKしてください。それでもダメなら、02 の「手順書をダウンロード」で保存して、「ダウンロードフォルダの codex-setup.md を読んで進めて」と送ってください。

  


  

    ChatGPT がメモリを全部書き出してくれない
    
ChatGPT の 設定 →「パーソナライズ」→「メモリ」の管理画面と、「カスタム指示」の画面のスクショを撮って、Codex に貼ってください。画像から書き起こしてくれます。

  


  

    新しいセッションで、前回のことを覚えていない
    
いちばん多い原因は、別のフォルダを開いていることです。Codex で開いているフォルダが記憶フォルダか確認してください。合っているなら「AGENTS.md のルールを読んで、今の状況を教えて」と送ってみてください。

  


  

    秘書の話し方が ChatGPT のときと違う
    
「もっと〇〇な感じで話して。secretary.md を直して」と伝えてください。backup/ に ChatGPT の原文が残っているので、「backup の原文を見て、話し方を近づけて」も効きます。

  


  

    Obsidian に何も表示されない
    
別のフォルダを保管庫として開いている可能性があります。Obsidian の左下の保管庫アイコン →「フォルダを保管庫として開く」から選び直してください。
